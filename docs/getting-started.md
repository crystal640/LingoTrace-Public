# LingoTrace 新手使用指南

本文面向第一次使用 LingoTrace 的英语学习者。你不需要会编程，但需要能够复制 ChatGPT 项目指令、复制 JSON，并在 LingoTrace 中完成导入。

## 1. 先理解它的分工

- **ChatGPT**：陪你练习，并在练习结束后按指定格式梳理学习内容。
- **LingoTrace**：保存、展示和复习结构化结果，包括日报、单词、句型与纠错。

LingoTrace 不会自动读取所有 ChatGPT 对话。当前版本通过手动 JSON 导入连接两者。

## 2. 配置 ChatGPT 项目

1. 在 ChatGPT 中新建一个专门用于英语口语练习的项目。
2. 打开仓库根目录的 `LingoTrace-英语口语项目指令.md`。
3. 复制文件的**全部内容**。
4. 粘贴到 ChatGPT 项目的“项目指令”区域并保存。

注意：只把 Markdown 文件上传到聊天中，不等于设置项目指令。为了让每次新对话都遵守相同 JSON 格式，必须将全文粘贴进项目指令。

## 3. 进行一次英语练习

可以使用文字或语音练习。建议每次围绕一个或几个真实主题，例如：

- 自我介绍和今天发生的事；
- 工作汇报或面试表达；
- 旅行场景；
- 对一部电影、一本书或新闻的观点；
- 用英语描述情绪和计划。

平时自然聊天即可，不需要每一轮都要求生成报告。

## 4. 生成日报 JSON

练习结束后，单独发送：

```text
生成 LingoTrace 日报
```

正常结果应满足：

- 回复只包含一个 JSON 对象；
- 开头类似 `{ "schema_version": "LINGOTRACE_REPORT_V1", ... }`；
- 没有“以下是你的报告”等解释；
- 没有 ```json 代码围栏；
- JSON 最后有完整的 `}`，没有被截断。

复制从第一个 `{` 到最后一个 `}` 的全部内容。

## 5. 导入 LingoTrace

1. 打开 [LingoTrace 在线版](https://lingo-trace.vercel.app/)并登录。
2. 在首页找到日报/记录导入入口。
3. 粘贴完整 JSON。
4. 阅读校验结果；没有错误后确认导入。
5. 返回首页查看当日概览与日报。

如果同一份日报被再次导入，系统会根据报告标识和当前合并逻辑处理；不要通过手工改 ID 的方式制造重复记录。

## 6. 导入后怎么学

### 首页与日报

先看总分和五个维度：流利度、语法、词汇、自然度和沟通。分数的意义是帮助你观察趋势，不是考试成绩。重点阅读定性评价、优势、改进建议和下一次目标。

### 单词

查看本次需要复习的词或短语，包括搭配、例句和来源语境。复习时按实际掌握情况更新状态，不要为了“清空任务”把模糊词标成已掌握。

### 纠错

对照原句和正确句，先自己解释差异，再展开系统说明。优先处理反复出现、会影响理解或与你近期话题高度相关的错误。

### 句型

句型库不是背诵清单。建议把一个句型替换成与你本人有关的内容，并在下一次 ChatGPT 对话中主动使用。

### 针对性练习

从纠错记录启动练习。每组包含三道四选一题，用于快速确认同一知识点。完成后仍建议在真实对话中再次输出该表达。

## 7. 推荐的日常节奏

```text
10–20 分钟英语对话
→ 生成并导入日报
→ 复习 3–5 个词
→ 复述 2–3 个句型
→ 完成 1 组纠错练习
→ 下一次对话主动复用
```

短而稳定的闭环通常比一次保存大量内容更容易坚持。

## 8. 安装到手机主屏幕

LingoTrace 是 PWA。浏览器支持时，可以通过浏览器菜单选择“添加到主屏幕”或“安装应用”。安装后会像普通 App 一样从图标启动，但仍由 Web 版本更新。

## 9. 常见问题

### ChatGPT 输出了说明文字或代码块

回复它：

```text
请严格按照项目指令重新生成。只输出合法 JSON 对象，不要代码块、标题或解释。
```

### JSON 导入失败

依次检查：

1. 是否复制了完整的首尾花括号；
2. 是否混入 Markdown 代码围栏；
3. 是否使用中文弯引号；
4. 最后一个字段后是否有多余逗号；
5. `schema_version` 是否为 `LINGOTRACE_REPORT_V1`；
6. `sentences` 是否恰好 10 条；
7. 回复是否因过长被截断。

不要在不理解字段含义时随意删字段。优先让 ChatGPT 按项目指令重新生成。

### 报告里出现了我没说过的话

要求 ChatGPT 重新生成，并强调“只分析当前练习中用户真实说过的内容”。项目指令已经规定真实性边界，但模型仍可能出错，因此导入前应快速检查。

### 分数为什么和上次差很多

评分会受话题难度、样本长度、语音转写质量和当次表现影响。更适合观察数周趋势和重复问题，不适合把单日波动视为能力定论。

### Gemini 不可用还能练习吗

可以。服务端包含确定性的本地回退题目，但题目变化和自然度可能不如 AI 生成版本。

## 10. 隐私提醒

- 导入前检查报告中是否包含不希望保存的姓名、公司或敏感事件。
- 不要把真实报告 JSON 提交到公开 GitHub Issue。
- 报错时如需分享 JSON，请先替换姓名、对话 ID、日期和私人内容。
